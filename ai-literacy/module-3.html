Tools That Transfer

Not a product tour. A checkable job (CRISP), a verify loop, and a decision about when a template already beats asking a model. Use any school-approved tool.

3 objectives CRISP rebuild 1 homework

Learning objectives

By the end of this module you will be able to:

  1. Rebuild a weak educator prompt with CRISP (Context, Role, Instruction, Specs, Proof).
  2. Name the verify steps you will run before anything student-facing.
  3. Decide when a template or existing workflow beats asking a model again.

Lesson

Any approved tool

This is not a bake-off. The habit transfers. If your district or campus has named a system, use that one. If it has not, stay inside whatever policy you already have, and do not paste red-line material into a free phone app (Module 1).

A tool change next year should not erase this week’s work. Context, specs, and proof still matter in whatever box they hand you.

CRISP turns a vague ask into a job

“Make a quiz” is a wish. “Ten items, grade 7, our textbook’s mechanism, no new vocabulary, I will check each item against chapter 4” is a job you can verify.

C
Context
Who the learners are, and what constrains the task. Time, prior knowledge, devices, the chapter you actually taught.
R
Role
Optional. A light persona, or none. Do not let “act as a world-class…” replace specs.
I
Instruction
The actual job. What should it produce?
S
Specs
Format, length, musts, avoids, reading level, what not to cover.
P
Proof
How you will check. “Flag any fact you are unsure about” belongs here.

CRISP is a habit, not a brand and not a vendor. Fill Context, Instruction, Specs, and Proof at minimum. Role can stay light.

Then the same verify loop

You already have it from Module 1. Claim check. Bias skim. Level check. Own it. Layout polish is not a substitute. If you would not put your name on it, it is not ready for students.

When a template beats a model

A model is useful when you need options to critique, a first draft of non-graded material you will edit, or differentiated starting points. It is a poor weekly engine for work you already know how to structure.

If the discussion stem is the same every week and only the reading title changes, keep a template. If you already have a comment bank for three rubric moves, mail-merge or copy the bank. If the quiz items exist and are good, use the quiz bank. Asking a model to “make a quiz” each Sunday is how Failure A (confident wrongness) gets a standing invitation.

Automation — a saved prompt, an LMS item, a spreadsheet, a simple Zap that files a form response — wins when the job is repeatable and the quality bar is already set. A model wins when the job is new and you will still verify.

K–12 example: a Friday exit-ticket stem you reuse with a new content slot. Higher-ed example: a weekly discussion contract (quote + warrant + question) that does not need a new generated “richer prompt” every Monday — that was Module 1’s board problem.

Homework

Homework: One class you teach. One CRISP prompt (Context, Role if any, Instruction, Specs, Proof). Then list the verify steps you will run before students see the output — or name the template you will use instead of a model, and why.
