# Facilitator note — Module 1: What GenAI Actually Does

For a PD lead running this async. A colleague note, not a vendor deck.

**Author frame (say this if asked; do not make it the opener).** Higher-ed faculty and faculty developer: NC A&T Lecturer (Critical Writing, Analytical Reasoning at large enrollment, Humanities); Director of Online Learning, 2008–2012 (Blackboard, faculty PD, online/hybrid). MFA, Creative Writing, UNCG. Designs learning and ships working prototypes by directing AI coding agents; not a software engineer. Has not held a K–12 teaching job. The K–12 scenario and lanes are written for the course audience.

## Time

About 25 minutes: lesson (~10), in-module practice (~10), homework prompt (~5). Practice lives in `module-1.html` — mental-model check, two failure modes, red lines, verify habit. Do not send people to a separate pack for this module. CRISP rebuild is Module 3.

## Objectives

By the end, educators can:

1. Explain generative AI in plain language without hype or fear.
2. Spot two classroom failure modes: confident wrongness and wrong level.
3. Name red lines (student PII, unpublished keys, IEP/health notes) and a verify habit before anything student-facing.

## Where to put the homework

Paste the prompt into an LMS discussion or journal this week. If there is no LMS, a shared doc is enough. The prompt asks for a class they actually teach, not how they feel about AI. If a cohort exists, skim posts for the two failure modes and one red-line mention; you do not need to grade them.

## Common snags

- Wanting a tool demo. This module is literacy, not a product tour. Tools are Module 3.
- Collapsing every issue into cheating. That is Module 2.
- Skipping verify because the output “looked done.” That is the point of Failure A.
- Pasting a real student name or IEP line into a tool while they practice. If you debrief, say that out loud once.
- K–12 participants asking who wrote “their” case. Point back to the author frame. Do not imply K–12 classroom experience.

## What not to claim

Do not introduce the author as a software engineer, a K–12 teacher, or a Storyline / Articulate / current-Canvas specialist. Do not call this a live institutional course. Do not use hype language (“unlock,” “rapidly evolving”) if you add a welcome note.

## Optional 15-minute live debrief

Only if a cohort exists. One confident-wrongness example from the room. One red-line check. Stop. Do not turn it into a tool bake-off.
