# Facilitator note — Module 3: Tools That Transfer

For a PD lead running this async. Colleague voice.

**Author frame (if asked).** Educator and online-learning lead who ships prototypes by directing AI coding agents; not a software engineer. Not a product trainer.

## Time

About 20 minutes: lesson (~7), CRISP rebuild + template-vs-model check (~8), homework (~5). Practice is in `module-3.html`. Use any school-approved tool. This is not a vendor tour.

## Objectives

1. Rebuild a weak educator prompt with CRISP (Context, Role, Instruction, Specs, Proof).
2. Name a verify loop they will run before anything student-facing.
3. Decide when a template or existing workflow beats asking a model again.

## Homework

One CRISP prompt for a task they actually teach, plus the verify steps they will run. If they would not use a model for that task, they say so and name the template they will use instead.

## Common snags

- Asking which chatbot is “best.” Redirect: approved tool + checkable job.
- Filling CRISP as decoration and skipping Proof. Proof is the habit.
- Using a model for a weekly task that already has a stable template (same discussion stem, same comment bank). Name that as a win.
- Pasting student work or live keys into the builder. The builder is local; the habit they take home is not.

## What not to claim

Do not demo a paid tool as required. Do not brand CRISP as a vendor method. Do not send them to a live tunnel or a studio homepage.

## Optional 10-minute debrief

One person reads a CRISP rebuild. One person names a task a template already handles. Stop.
