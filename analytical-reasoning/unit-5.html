Unit 5 · When the comparison holds · ~35 minutes

Analogies and categories

A comparison is a reason only if the shared feature is the one the claim needs. If that feature is different, you have a picture, not a pipe.

3 objectives Practice with feedback 1 homework

After the practice

  1. Name the shared feature an analogy is asking you to treat as the one that matters.
  2. Say when a comparison breaks — which difference would change the conclusion.
  3. Sort a case into a category and state the rule you used to sort it.

Lesson

People reason with likeness. “This attendance policy is just like a job. If you don’t show, you don’t get paid.” That sentence is doing two jobs at once. It is painting a picture, and it is smuggling a rule: class is the kind of thing where absence costs you the good the meeting was for. If that rule is the one we should use, the analogy holds. If class is also the kind of thing where the meeting is practice, and the grade is supposed to measure the skill, not the chair time, the analogy leaks. Same picture. Different rule.

An analogy is cheap when no one names the shared feature. Your job is to write that feature in a sentence. “Both are scheduled obligations with other people waiting on you” is a candidate. “Both involve a building you walk into” is not. The second one is true and idle.

Then apply Unit 2’s test. If the shared feature were missing, would the conclusion still follow? If we imagine a class that is self-paced, recorded, and graded only on a portfolio, does “it’s like a job” still force an attendance dock? Probably not. Name which feature you mean. A classmate can now accept or reject the feature instead of fighting the picture.

Categories are analogies that have been given a rule. When you say “this is a safety issue, not a convenience issue,” you are placing a case in a bin that already has a policy attached. Bins are useful. They are also where arguments hide. If late lighting on one path is a safety issue, the bin may buy a work order. If every inconvenience is recoded as safety, the bin stops meaning anything.

Campus talk loves two bins: fairness and respect. Both matter. Neither is a substitute for a rule. “It isn’t fair that the 8 a.m. section has no open lab” might mean the two sections were promised the same access, or it might mean I am unhappy. Write which one you mean.

A comparison also breaks when the scale is wrong. “If we allow one make-up quiz, we have to allow them all” treats one case as a category. Sometimes that is honest: you do not have a way to tell the cases apart. Sometimes it is a slide. Name the difference that would stop it, or admit you do not have one.

Practice

What has to travel?

“Lab attendance should work like a job: if you don’t show, you lose the day’s pay (credit).”

Practice

When does it break?

Which difference would most weaken the job analogy for a lecture that is recorded and graded only on two exams?

Practice

Sort with a rule

Case: a posted notice says the east-lot lights are out on the walk from the late lab. Someone calls it a safety issue; someone else calls it a convenience issue.

Write one rule for the safety bin — what has to be true of a case to go in it — and say whether this case meets it. Two sentences.

Homework

150–220 words. Catch one comparison you can point to.

Catch one analogy or category in the wild: a syllabus policy, a roommate argument, a public comment, a posted comparison (“this is just like…”). In 150–220 words: (1) quote or paraphrase the comparison; (2) name the shared feature that would have to travel; (3) name one difference that would break it; (4) rewrite the claim without the picture, using only the feature you are willing to defend. Do not invent the original comparison.
