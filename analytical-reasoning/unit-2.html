Unit 2 · What has to be true · ~35 minutes

Hidden assumptions

Every short argument leaves something unsaid. The assumption is the unsaid piece the argument needs. If it fails, the because no longer reaches the claim.

3 objectives Practice with feedback 1 homework

Learning objectives

By the end of this unit you will be able to:

  1. Name the unstated premise a short argument needs in order to reach its claim.
  2. Distinguish a load-bearing assumption from a restated conclusion or a side fact.
  3. Say what happens to the argument if that assumption is false.

Lesson

Unit 1 asked you to put a because on the table. Unit 2 asks what else has to be true for that because to reach the claim. That missing piece is the assumption. It is not a guess about the speaker’s secret motives. It is the plank the argument stands on and does not mention.

Take a campus sentence: “The rec center is packed at 5, so we should build another gym.” The because is a crowd at 5. The claim is a building. What has to be true? At least this: that the 5 o’clock crowd is typical, not a one-week spike; that the problem is space, not staffing or hours; that another building is a better fix than stretching the hours you already have. If any of those is false, the packed room can still be real and the building still does not follow.

That last sentence is the whole unit. A true because can sit next to a claim it does not earn. The gap is the assumption. Your job is to say the gap in a sentence a classmate could accept or reject.

A useful test: if this were false, would the because still get you to the claim? If the answer is no, you found a load-bearing assumption. If the answer is yes, you found something the speaker might also believe, but the argument does not need it. “People like gyms” might be true. The packed-at-5 argument does not stand or fall on whether people like gyms. It stands or falls on whether the crowd means we lack space that another building would fix.

Students sometimes confuse the assumption with the conclusion. The conclusion is what the speaker wants. The assumption is what they skipped. “We should build another gym” is not the assumption. It is the claim. The assumption is quieter: the current building, used as it is now, cannot absorb the 5 o’clock demand. Write that sentence. Now someone can argue with the quiet part instead of just liking or hating the building.

Another mix-up: treating a background fact as the assumption. “There is a rec center” is background. Everyone in the argument already granted it. Assumptions worth marking are the ones a reasonable opponent could deny. In a large first-year section, this is the move that separates a recap from an analysis. Recap repeats what was said. Analysis says what had to be true.

Assumptions come in two everyday flavors. One is a fact that was skipped: the 5 o’clock crowd is typical; the waitlist is still there on Fridays; the shuttle that “always” skips stops skipped them this week. The other is a standard that was skipped: packed means we must build, not shift hours; a twenty-minute wait is too long; “enough” dining means a hot line after 8. Fact-assumptions you check against the world. Standard-assumptions you put on the table so people can argue about the rule instead of about each other’s taste.

Logic tutoring likes to call these necessary assumptions and then dress them in extra vocabulary. Keep the plain version. Ask: what has to be true? Then ask: what happens if it isn’t? If the argument dies, you found the plank. If the argument limps but still walks, you found a helper, not the plank.

You do not have to agree with the assumption to name it. Naming it is a public service. In civic talk this is how a conversation gets less personal. “You just want to spend money” is a motive story. “Your argument assumes the 5 o’clock crowd is typical year-round” is a check. The first one starts a fight. The second one starts a look at the calendar.

Be careful not to invent a worse version of the speaker. That is a later unit (straw person). The assumption you write should be the kindest load-bearing sentence that still has to be true. Not the dumbest one you can pin on them. If they said the rec is packed at 5, do not write “they assume nobody has anything better to do.” Write the sentence their because actually needs.

Practice here: mark the assumption, say which one is load-bearing, and write the missing premise so a classmate could accept or reject it. Homework asks you to do the same to a real short argument you did not invent.

Practice

Mark the assumption

Argument: “Office hours are empty on Friday afternoon, so the instructor must not be helpful.” What has to be true for emptiness to mean “not helpful”?

Practice

Which plank is load-bearing?

Argument: “The wait for tutoring is forty minutes on Sunday, so we should hire three more tutors.”

Practice

Write the missing premise

Argument: “Almost no one voted in the student-government election, so the senate does not represent us.”

Write one sentence that starts with This argument assumes that… Make it load-bearing. If your sentence were false, the low turnout would no longer get you to “does not represent us.”

Homework

Turn this in if you have a section that wants it. Do not invent the argument.

Take one short argument from a posted campus notice, a city or county agenda item you can point to, a roommate, or a class discussion. Quote or paraphrase it in two sentences (claim + because). Then write the load-bearing assumption in one sentence: “This argument assumes that…” Then write one sentence saying what happens to the argument if that assumption is false. 150–220 words. Do not attack the speaker. Name the plank.
