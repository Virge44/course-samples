Unit 6 · The trap he already teaches · ~40 minutes

Correlation is not causation

Association is a pattern. Causation is a lever. If you already refuse the leap in ordinary talk, do the data version here: name the confounder, drop the causal verb.

3 objectives Practice with feedback 1 homework

Learning objectives

By the end of this unit you will be able to:

  1. Describe an association without using a causal verb.
  2. Name a plausible confounder or a reverse-causation story for a short EXAMPLE.
  3. Rewrite a headline so the table’s pattern remains and the lever is gone.

Lesson

If you already did Analytical Reasoning 101, you have met this trap in ordinary talk: a because that treats a together-with as a made-by. This unit is the same refusal, in data clothes. Association is a pattern in a table or a scatter. Causation is a claim that changing one thing would change the other. Those are different sentences. The verbs are the leak.

This sample is still not a statistics-department course. You will not fit a line with software. You will name an association, name a confounder, and rewrite a causal verb the table did not earn. The muscle is from the reasoning course and from logic tutoring: what has to be true for this leap to work? Here what has to be true is a story about a mechanism, not only a cloud of dots.

EXAMPLE (classic teaching story, invented as a classroom object, not a city study): towns with more ice-cream sales also have more swimming-pool visits. A headline that says “ice cream causes swimming” has left the table. Heat is sitting in the room. Heat sells ice cream and fills pools. That third variable is a confounder — a something else that can produce the association without either column causing the other.

Reverse causation is the other common leak. People who carry umbrellas are more often wet. The umbrella did not summon the rain. The rain summoned the umbrella. A table of “device use” and “sleep” can run either direction, or both, or neither. If the write-up uses leads to, boosts, makes, or because of, ask which way the arrow was tested. A snapshot rarely tests an arrow.

Coincidence is allowed. With enough columns, some pairs will line up. That is not a finding about the world. It is a finding about hunting. Unit 7 will come back to this as “significant” theater. For now: an association you found by scrolling until one looked pretty is a weaker object than an association you predicted before you looked.

You do not need software to picture the pattern, but it helps to know what a scatter is claiming. Each point is a pair: this town’s ice-cream sales, this town’s pool visits. A cloud that leans up and to the right is a positive association. A cloud with no lean is little association. The picture can hide the same things Unit 3 named: a truncated axis, a missing n, a window of years. A pretty cloud is still not a lever.

What would start to buy a causal claim, even in a 101? A mechanism you can name. A time order (the supposed cause sits before the effect). A comparison that holds the confounder still — or, in stronger designs you will only hear about here, random assignment. This course will not pretend a gen-ed sample can certify a cause. It will insist that you not sell one from a scatter.

Correlation, as a word, just means the two columns move together in some indexed way. Positive: both tend to rise. Negative: one rises as the other falls. Strong or weak is “how tightly,” not “how important.” A tight association can still be confounded. A weak association can still be causal and buried in noise. Strength is not a verdict.

Rewrite practice is the grade. “Ice cream sales and pool visits rose together in this EXAMPLE. That does not show that ice cream fills pools. Heat is a plausible confounder.” Notice what that paragraph did not do. It did not sneer. It did not deny the pattern. It took the causal verb off the payroll.

Campus and civic talk will hand you softer verbs that still leap: linked to, tied to, associated with higher risk of — and then a policy as if the lever were proven. Linked-to can be honest. Policy needs a lever. Analytical Reasoning 101 would call the policy the claim and the table a because that has not yet clocked in. Keep that split.

Practice: mark the leap, name the confounder, and rewrite without a causal verb. Homework: find a real headline or caption that treats a together-with as a made-by. Repair it. Do not invent a study.

Which sentence stays with the table?

Practice

Name the third thing

EXAMPLE (invented teaching pair, not a study): in a stack of towns, libraries with more children’s books also have higher reading-test averages. Which is the fairest next thought?

Practice

Rewrite without the lever

Headline (EXAMPLE, invented, not a real story): “Late-night phone use makes students sleep less.” The only object behind it is a snapshot: people who reported more late-night phone minutes also reported fewer sleep minutes. Rewrite one or two sentences. Keep the pattern. Drop makes. You may name reverse causation or a confounder.

Homework

Find one real public headline, caption, or press blurb that treats a together-with as a made-by. A news desk, a government release, a posted chart. Do not invent a study. Copy the sentence. Then, in 150–220 words: (1) What association, if any, is actually claimed? (2) Name a confounder or a reverse-causation story. (3) Rewrite the sentence so the pattern can stay and the lever is gone. If you already did Analytical Reasoning 101, add one sentence on what is the same refusal and what is new (a table, a scatter, a named confounder).
